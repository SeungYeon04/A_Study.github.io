### 기본 용어 

AI: 인공적인 지능 - 인간 지능 모방 시스템 (Artificial Intelligence)  
ML: 기계 학습 - 대규모 데이터를 통해 패턴 학습 예측 의사결정 개선 (Machine Learning)  
DL: 딥러닝 - 인간 뇌처럼 인공신경망(ANN) 써서 수많은 은닉계층 만듦. 정말 딥하게 학습 (Deep Learning)  
  
셋 다 범주의 차이. AI는 모두 포괄한 말.  
그 안에 학습법이 ML 그게 딥하면 DL  
  
### 학습 종류 

지도학습: 문제와 정답 세트를 주고 판단을 시켜 패턴 학습 -> 예측  
비지도학습: 정답 없이 데이터의 특징 패턴만 찾도록 시킴. 묶어서 구조 찾기  
강화학습: 행동에 대한 보상을 줘서 최적을 찾음.  
  
강화학습에서 필요한 것들이며  
분류모델은 결과를 종류로 나누는 것 (좋다/싫다, 고양이/개)  
예측모델은 결과를 숫자로 예측하는 것 (가격, 확률 등)  
LLM은 이 셋을 다 씀.  
  
LLM 학습: 처음에는 정답을 안 주며, 데이터의 패턴을 보고  
다음에 올 데이터를 예측하게 학습한다.  
이후에는 틀린 답을 줄여가며 점점 더 정확하게 만든다.  
그 다음 예측을 제공해주는 건 "파인튜닝"  
  
데이터 사이언스: 데이터로부터 정보와 의미를 추출해  
컴 등이 이해할 수 있도록 가공해준다 보면 됨.  
  
### 데이터 종류 

- 정형데이터: 엑셀, DB 등 정렬된 데이터  
- 시계열데이터: 시간 흐름에 따라 기록한 데이터  
(정형일 수도 비정형일 수도 있음.)  
- 비정형데이터: 형태가 있지 않아. 전처리 필요 데이터  
  
### 전처리 

1. 결측/이상치 제거 (불균형 합/불 버리기 최소화 판단 포함. 재활용)  
2. 데이터 변환 (학습을 위한 적절한 형태)  
3. 데이터 증강 (데이터 양 증가, 적은 클래스 DB 쪽 늘려 비율 맞추기)  
  
- 결측치: 빈 값.  
ㄴ 결측치처리: 컬럼이 중요한 값이고 유의미 해야하거나, 변수가 넘 적으면 어캐든 살리기.  
- 이상치: 혼자 팍 크고 팍 작은 값  
ㄴ 이상치처리: 모델 기능 저하 우려가 있으니 그냥 제거  
  
전처리 이야기: 정형 데이터라고 해도 형태는 여러가지일 수 있음.  
어떤 건 스트링(지역 등) 들어가는데 컴퓨터한테 그대로 준다?  
아니면 단위가 다르거나 하면 처리 어려움.  
  
#### 전처리 단계 (옛 기준) 
```
- 스케일링: 단위(Unit) 초기화 (단위를 맞춰주기)  
- 범주형 데이터처리:  
	- Label Encoding: 0.. 1... 2... 이렇게 라벨 달아줌  
	- One-Hot Encoing: 0과 1로 이루어진 행렬(Matrix)로 변환  
```
  
분류모델도 예측하기도 함.  
(정답 안 받고 뭐 이것저것 하는데 뭐... 그럴만 함.)  
분류모델은 예측모델의 하위 개념 중 하나라 생각하면 됨.

### 머신러닝 모델 종류 

#### 의사결정트리 (Decision Tree) 

: 분류모델  
거의 if문 로직 생각하면 됨.  
True False 로 뻗은 결정 트리  
  
#### 로지스틱 회귀 (Logistic Regression) 

: 분류모델 (예측모델로도 성능 좋은 편)  
거의 방정식 생각하면 됨.  
데이터셋에서 선형 방정식으로 처리 후,  
가중치(기울기)로 확률 변환해 계산함.  
  
범주형 데이터 예측을 위해 확률을 계산하며, 곡선 형태를 가짐. 예측모델로도 사용 가능  
  
#### K-NN / K-최근접이웃 (K-Nearest Neighbors) 

데이터끼리 거리가 가까운지  
K: 원형 군집에 들어오는 구성원 수  
데이터 간 거리 기준으로 가장 가까운 K개의 이웃을 찾고, 다수 클래스 기준으로 분류함  
  
#### SVM / 서포트 벡터 머신 (Support Vector Machine) 

처음엔 데이터가 좌표 공간에 점으로 흩어져 있음.  
데이터 구분용 선 or 평면 그어서  
각 클래스와의 거리를 최대화하여 분류함.  
  
> 이 모델들은 정확하지 않고, 장단점이 있음. 
  
### 앙상블 모델 

- Bagging : N의 데이터 셋으로 여러 모델을 각각 학습해 결과를 모아서 사용  
- Boosting : 모델이 N 데이터에서 틀린 부분을 찾아 가중치를 주고  
다음 모델이 또 받아서 학습 가중치 반복 (쓸만해짐)  
- Stacking : 여러 모델을 학습시키고, 그 예측 결과를 입력으로 새로운 모델을 학습  
이 친구 과적합 잘 나옴. 너무 잘 배워서 학습데이터에 너무 치중이 된.  
  
### 그 이상 발전 버전 

Neural Network : 뇌 정보 처리 방식 영감된 알고리즘  
  
하나의 망으로 전기신호. 뉴런네트워크  
하나의 뉴런이 하나의 분류모델  
  
뉴런 하나 단위: Perceptron  
  
- 층구조: 입력층, 은닉층(뎁스(히든층)이 깊어지면 딥러닝), 출력층

### 뉴런 네트워크 모델 (신경망 기반 모델) 

> 1. CNN (Conrolutional Neural Network) : 인간 시신경 구조 모방. 이미지 패턴 찾기 좋음.  
> 2. RNN (Recurrent Neural Network) : 입출력 시퀀스 단위로 처리. 순환해서 돌기. 시계열 처리.  
> 단점: 기울기소실(역전파 과정에 기울이를 계속 곱하다 0돼서 소실), 장기의존성(오래되면 유실)  
> 3. LSTM (Long Short-Term Memory) : 학습된 가중치를 이용해 게이트를 지정해  
> 정보 유지를 조절. 긴 시퀀스 처리 가능. 기울기 소실 문제 보완.  
> 4. LLM (Long Language Model) : LLM도 뉴런 네트워크에 속함.  
> 트랜스포터 인포메이션 나오면서 나옴  
> 원래는 순차만 하다가 트랜스포머 나오고 병렬 처리를 해서 빨라짐.
